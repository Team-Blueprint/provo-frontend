## Public artisan directory (`GET /workers/available`)

Returns available artisans filtered by optional `trade` and `area` query parameters.

<ResponseField name="id" type="uuid">
  Artisan user ID.
</ResponseField>

<ResponseField name="name" type="string">
  Display name.
</ResponseField>

<ResponseField name="trade" type="TradeType">
  Primary registered trade.
</ResponseField>

<ResponseField name="verified_days_count" type="integer">
  Count of settled `PAID` work days.
</ResponseField>

<ResponseField name="badge_grade" type="string">
  `UNVERIFIED`, `BRONZE_VERIFIED`, `SILVER_VERIFIED`, or `GOLD_VERIFIED`.
</ResponseField>

## Worker record, settings & lender sharing

| Method | Path | Auth | Description |
| :--- | :--- | :--- | :--- |
| `GET` | `/workers/{worker_id}/record` | Worker / Admin | Full work record and daily verification metrics |
| `GET` | `/workers/{worker_id}/payment-link` | Worker | Retrieve persistent shareable payment link and Paga account details |
| `GET` | `/workers/{worker_id}/settings` | Worker | Read payout account, availability, and alert channel preferences |
| `PATCH` | `/workers/{worker_id}/settings` | Worker | Update payout account, trade, area, or availability |
| `GET` | `/workers/{worker_id}/shares` | Worker | List active and revoked lender share tokens |
| `POST` | `/workers/{worker_id}/shares` | Worker | Create a consented, expiring lender report link |
| `POST` | `/workers/{worker_id}/shares/{token}/revoke` | Worker | Immediately revoke a lender share token |
| `GET` | `/reports/{token}` | Public (token-gated) | Return lender report with tokenized employers and 0–100 score (`410` if revoked/expired) |
