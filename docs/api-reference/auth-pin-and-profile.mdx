## Get current user (`GET /auth/me`)

Requires `Authorization: Bearer <access_token>`.

<CodeGroup>
```bash curl
curl https://api.useproofwork.ng/auth/me \
  -H "Authorization: Bearer <access_token>"
```

```json 200 OK
  "payout_account_number": "1092837465",
  "payout_bank_code": "PAGA",
  "needs_pin_setup": false
}
```
</CodeGroup>

## Set web PIN for Telegram accounts

If `needs_pin_setup` is `true`, request an SMS code and save a 6-digit PIN:

<CodeGroup>
```bash 1. Request PIN setup OTP
curl -X POST https://api.useproofwork.ng/auth/request-set-pin \
  -H "Content-Type: application/json" \
  -d '{ "phone": "+2348123456780" }'
```

```bash 2. Set 6-digit PIN
curl -X POST https://api.useproofwork.ng/auth/set-pin \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "+2348123456780",
    "otp_code": "482910",
    "new_pin": "654321"
  }'
```
</CodeGroup>

## Refresh access token (`POST /auth/refresh`)

```bash curl
curl -X POST https://api.useproofwork.ng/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{ "refresh_token": "<refresh_token>" }'
```
