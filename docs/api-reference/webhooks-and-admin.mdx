## Paga webhook (`POST /webhooks/paga`)

Ingests Paga Collect payment callbacks.

- **Headers:** `X-Paga-Signature` or `hash` (raw-body SHA-512 HMAC).
- **Idempotency:** Deduplicates on `paga_event_id` in `payments_in`.
- **Reconciliation:** Sums cumulative payments for the matched `job_id`, moving to `FUNDED` on exact match or handling under/overfunding.

## Telegram webhook (`POST /webhooks/telegram`)

Ingests updates from the Telegram Bot API, validated by `X-Telegram-Bot-Api-Secret-Token`.

## USSD simulator (`/ussd`)

| Method | Path | Description |
| :--- | :--- | :--- |
| `GET` | `/ussd/balance` | Fetch worker's settled and pending balance by phone |
| `GET` | `/ussd/pending-jobs` | List funded jobs awaiting daily completion |
| `POST` | `/ussd/report-done` | Mark a work day done from a USSD session |
| `POST` | `/ussd/withdraw` | Trigger withdrawal to the worker's Paga payout account |
| `POST` | `/ussd` | Interactive USSD gateway menu handler (`*123#`) |

## Sandbox simulator (`POST /sandbox/simulate-deposit`)

Simulates an inbound Paga Collect bank transfer for an `AWAITING_FUNDING` job in sandbox/demo environments.

## Admin operations (`/admin`)

Requires `is_admin = true`.

| Method | Path | Description |
| :--- | :--- | :--- |
| `GET` | `/admin/disputes` | List open and resolved day disputes |
| `GET` | `/admin/outbox` | Inspect outbox payout queue and settlement attempts |
| `POST` | `/admin/disputes/{dispute_id}/resolve` | Resolve an `OPEN` dispute (`RELEASE_TO_WORKER`, `REFUND_TO_CLIENT`, or `SPLIT`) |
