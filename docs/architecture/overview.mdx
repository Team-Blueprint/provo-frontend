The Provo backend is built in **Python 3.12** with **FastAPI**, **Pydantic v2**, and **SQLAlchemy 2.0** (async) backed by PostgreSQL / SQLite and Alembic migrations.

## Repository layout

| Layer | Directory | Responsibility |
| :--- | :--- | :--- |
| **Domain** | `app/domain/` | Pure Python with zero DB or network calls: `lifecycle.py`, `ledger.py`, `scoring.py`, `fraud.py`. |
| **Services** | `app/services/` | Transactional use cases (`job_service`, `funding_service`, `release_service`, `report_service`, `auth_service`). |
| **Integrations** | `app/integrations/` | `PagaClient` (real + simulated adapter behind one interface), `aiogram` Telegram bot, SMS gateway. |
| **API** | `app/api/` | FastAPI routers for `auth`, `jobs`, `workers`, `reports`, `webhooks`, and `admin`. |
| **Workers** | `app/workers/` | Background scheduler (`SELECT ... FOR UPDATE SKIP LOCKED` for 24h auto-release) and outbox payout worker. |
| **Frontend** | `frontend/src/` | React 19 + TypeScript + Vite + Tailwind CSS v4 + `reicon-react` + `proofwork-tokens.css`. |

## Swappable data & integration adapters

- **Backend Paga adapter:** Live Paga Collect / Business REST client and a deterministic fake client share the exact same interface so end-to-end tests and offline demos run identically.
- **Frontend API mode:** `src/api/client.ts` switches cleanly between `mockAdapter.ts` (seeded Emem Ekpo data in `localStorage`) and `httpAdapter.ts` (`VITE_API_BASE_URL`) via `VITE_API_MODE=live`.
